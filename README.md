# BearBuddy

**A University of Cincinnati Student Companion App**

BearBuddy is a mobile application designed to help University of Cincinnati students navigate campus, manage their schedules, and improve their online security, all in one place.

## About the Project

Created for Group 49's 2026/2027 Senior Capstone Project. College students often rely on multiple applications to manage their classes, schedules, campus navigation, and online accounts. BearBuddy aims to bring these essential tools together into one convenient platform designed specifically for UC students.

The application focuses on three main areas:

- **Campus Navigation:** Find buildings and classrooms, plan routes between locations, and account for potential obstacles such as construction and blocked pathways.
- **Schedule Management:** Organize class schedules and use class locations to help plan travel time between classes.
- **Student Security:** Organize important account information, encourage secure password habits, and help reduce password reuse.

## Planned Features

- Interactive University of Cincinnati campus map
- Building and classroom locations
- Route planning and estimated travel times
- Campus obstacle and construction information
- Student class schedule management
- Integration with mapping and location-based APIs
- Secure student information management
- Password reuse prevention
- Single sign-on (SSO) authentication

## Technologies

The technologies planned for this project include:

- **Frontend:** React Native
- **Backend:** Node.js and Express
- **APIs:** Google Maps API, Canvas LMS API, and other necessary APIs
- **API Testing:** Postman
- **Version Control:** Git and GitHub
- **Documentation:** Microsoft 365

> **Note:** The technology stack may change as development progresses.

## Project Goals

- Create an easy-to-use mobile application for UC students.
- Help students navigate campus more efficiently.
- Combine class schedules and travel information in one place.
- Promote better online security habits.
- Develop a functional prototype that can be tested and improved using student feedback.

## Security & Privacy

Security and responsible data handling are important considerations in BearBuddy's development.

- Development will prioritize protecting student information.
- Security features will encourage unique and secure passwords.
- Testing will use synthetic data where possible.
- The application will follow relevant university policies and ethical development practices.
