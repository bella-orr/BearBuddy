# User Stories

## Campus Navigation

- **US-1.1:** As a student, I want to view an interactive campus map so that I can navigate around campus.
- **US-1.2:** As a student, I want to search for campus buildings so that I can quickly find a specific location.
- **US-1.3:** As a student, I want to view building and classroom locations so that I know where my classes are located.
- **US-1.4:** As a student, I want to select a starting location and destination so that I can find a route between locations.
- **US-1.5:** As a student, I want to receive walking directions and estimated travel times so that I can plan how to get to my destination.
- **US-1.6:** As a student, I want to see construction or blocked pathways so that I can avoid unavailable routes.

## Schedule Management

- **US-2.1:** As a student, I want to add my classes to the app so that I can keep my schedule organized.
- **US-2.2:** As a student, I want to view my daily and weekly schedule so that I can plan my time.
- **US-2.3:** As a student, I want to edit or delete classes so that my schedule stays up to date.
- **US-2.4:** As a student, I want to associate my classes with their buildings so that I know where I need to go.
- **US-2.5:** As a student, I want to see the estimated travel time between classes so that I can plan when to leave.
- **US-2.6:** As a student, I want to receive a warning when I may not have enough time to travel between classes so that I can plan accordingly.

## Student Information and Security

- **US-3.1:** As a student, I want to securely log in so that my information is protected.
- **US-3.2:** As a student, I want to use SSO when available so that I can access the app using my university account.
- **US-3.3:** As a student, I want to organize my account and website information so that I can keep it in one place.
- **US-3.4:** As a student, I want to view my saved account information so that I can easily access it when needed.
- **US-3.5:** As a student, I want my personal information to be protected so that unauthorized users cannot access it.
- **US-3.6:** As a student, I want to manage my account settings so that I can control my app preferences.

## General Application

- **US-4.1:** As a student, I want to access BearBuddy from my mobile device so that I can use it while on campus.
- **US-4.2:** As a student, I want simple and consistent navigation so that I can easily find the features I need.
- **US-4.3:** As a student, I want helpful error messages so that I understand when something goes wrong.
- **US-4.4:** As a student, I want the app to load efficiently so that I can quickly access the information I need.
- **US-4.5:** As a student, I want the app to support accessibility features so that I can use it regardless of my accessibility needs.
- **US-4.6:** As a student, I want the app to handle unavailable external services so that I can still use available features when an API is unavailable.
